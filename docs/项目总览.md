# 项目总览

## 项目目标

“之一的工作台”是一个前后台一体的个人工作台：前端负责跨终端展示和交互，
GitHub 仓库负责数据版本管理，Serverless 后端负责认证、权限和安全写入。

## 技术栈

| 层级 | 当前方案 |
| --- | --- |
| 前端框架 | React 18 |
| 构建工具 | Vite |
| 路由 | React Router 6，使用 HashRouter |
| UI | Ant Design 4 |
| 请求 | 原生 fetch 封装 |
| 静态发布 | GitHub Pages + gh-pages |
| 数据仓库 | `STILL8PM/still8pm.github.io` |
| 后端方向 | Serverless，厂商待定 |

## 目录说明

```text
document/
├─ index.html                 Vite HTML 入口
├─ vite.config.js             构建、相对资源和开发代理配置
├─ package.json                启动、构建、预览、部署脚本
├─ .env.example                前端公开环境变量模板
└─ src/
   ├─ main.jsx                 React 挂载入口
   ├─ App.jsx                  全局布局与路由入口
   ├─ components/              可复用视觉组件
   ├─ pages/                   页面模块
   ├─ 配置/                    环境配置
   ├─ 公共/                    请求、认证、GitHub 数据源
   └─ 工作台/                  工作台全局上下文
```

## 关键边界

- `document/src/App.jsx` 是应用装配入口，新增页面首先在这里注册路由。
- 页面不能直接拼接 GitHub API 或自行调用 `fetch`。
- GitHub Token、OAuth Secret 等敏感信息不得进入前端代码、`.env.example`、
  `localStorage` 或 GitHub Pages 构建产物。
- GitHub Pages 只承载静态前端，不能承担安全的 GitHub 写操作。
- `docs/` 只保存项目知识和约定，不作为运行时数据目录。
