# 接口与数据模型

完整接口草案见 [`document/之一的工作台接口约定.md`](../document/之一的工作台接口约定.md)。

## 后端接口清单

| 方法 | 路径 | 是否需要登录 | 用途 |
| --- | --- | --- | --- |
| GET | `/api/session` | 否 | 获取会话 |
| GET | `/api/storage/status` | 是 | 获取当前存储提供商状态 |
| GET | `/api/admin/storage` | 是，需要系统配置权限 | 获取脱敏存储配置 |
| PUT | `/api/admin/storage` | 是，需要系统配置权限 | 更新存储配置 |
| POST | `/api/admin/storage/test` | 是，需要系统配置权限 | 测试候选配置连通性 |
| GET | `/api/data/:collection` | 是 | 查询集合 |
| GET | `/api/data/:collection/:id` | 是 | 查询单条数据 |
| PUT | `/api/data/:collection/:id` | 是 | 保存数据 |
| DELETE | `/api/data/:collection/:id` | 是 | 删除数据 |
| GET | `/api/auth/github?mode=login` | 否 | GitHub 登录 |
| POST | `/api/auth/logout` | 是 | 退出登录 |

## 存储提供商

后台配置 `storageProvider`，可选值：

- `github`：使用 `STILL8PM/still8pm.github.io` 和配置分支。
- `nutstore-webdav`：使用坚果云 WebDAV 根目录。

两种提供商实现相同的数据操作。GitHub 使用文件 SHA 作为版本号；WebDAV 使用
资源 ETag 或最后修改版本。前端不接触两种提供商的账号密码或访问令牌。

更新存储配置时，后台必须先测试候选配置，测试成功后再原子切换。读取配置时
只能返回脱敏账号和“凭据已配置”状态，不能返回 Token 或 WebDAV 应用密码。

## 数据存储建议

默认数据存储：GitHub 仓库 `STILL8PM/still8pm.github.io`。也可以切换到坚果云
WebDAV，目录结构保持一致。

建议数据目录：

```text
data/
├─ 工作台配置.json
├─ 用户偏好.json
├─ 文档索引.json
└─ 业务数据/
```

具体业务字段暂不确定，新增字段前先补充数据模型、读取方、写入方、默认值和
迁移策略，避免直接把页面状态当成持久化结构。

## 模块功能数据

本地管理数据版本为 `2`，模块和功能统一保存在扁平 `modules` 集合中。`type` 为
`module` 的记录是树根，`type` 为 `feature` 的记录通过 `parentId` 关联所属模块。

```json
{
  "id": "feature-notes",
  "type": "feature",
  "parentId": "module-productivity",
  "name": "知识笔记",
  "description": "记录和整理知识内容",
  "route": "/notes",
  "icon": "FileTextOutlined",
  "visibility": "permission",
  "permissionId": "content:read",
  "status": "enabled",
  "sort": 10,
  "updatedAt": "2026-09-07 09:30"
}
```

字段约束：

- `type`：只能是 `module` 或 `feature`。
- `parentId`：模块固定为 `null`；功能必须引用现有模块。
- `route`：模块为空字符串；功能必须以 `/` 开头且全局唯一。
- `visibility`：`public`、`authenticated` 或 `permission`。
- `permissionId`：仅 `permission` 可见范围需要填写。
- `status`：`enabled` 表示允许前台显示，`disabled` 表示隐藏。
- 删除模块时同时删除直接归属的全部功能，操作写入审计日志。

## 必须处理的异常

- `UNAUTHORIZED`：跳转登录或清理失效会话。
- `FORBIDDEN`：显示权限不足，不重复重试。
- `NOT_FOUND`：显示空状态或创建入口。
- `CONFLICT`：重新获取版本并提示用户处理冲突。
- `RATE_LIMITED`：显示限流信息，按响应时间等待后重试。
- `VALIDATION_ERROR`：展示字段错误，不提交无效数据。
- `NETWORK_ERROR`：保留本地草稿并提供重试。
