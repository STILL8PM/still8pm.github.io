# 之一的工作台项目文档

## AI 快速入口

修改项目之前，按以下顺序阅读：

1. [项目总览](./项目总览.md)：确认技术栈、目录、运行边界和当前状态。
2. [功能与逻辑](./功能与逻辑.md)：理解应用启动、路由、工作台状态和数据流转。
3. [公共方法](./公共方法.md)：优先复用已有配置、请求、认证和数据源方法。
4. [接口与数据模型](./接口与数据模型.md)：修改 GitHub 数据或后台接口前必读。
5. [路由与部署](./路由与部署.md)：涉及页面地址、构建或发布时必读。
6. [AI 修改指南](./AI修改指南.md)：执行修改前后的安全检查和验证要求。

## 文档维护规则

- 每次新增页面、公共服务、接口或数据字段，都同步更新对应文档。
- 文档描述必须以代码、构建结果、接口约定或部署配置为依据。
- 未实现的后台能力标记为“待实现”，不得写成已经可用。
- 重要变更记录文件路径、变更原因、影响范围和验证命令。

## 当前状态

- 前端：React 18 + Vite + React Router 6 + Ant Design 4。
- 发布：GitHub Pages，构建输出目录为 `document/build/`，发布命令为 `npm run deploy`。
- 数据：支持 GitHub Repository 和坚果云 WebDAV，前端通用存储契约已建立。
- 后台：Serverless 接口尚未部署，认证和真实存储读写仍待实现。
- 最近验证：在 `document/` 执行 `npm.cmd run build` 成功。
