# 公共方法

## 使用原则

业务页面优先使用工作台上下文提供的实例，不自行创建请求客户端，不在页面内
保存 GitHub 凭据，不重复实现加载、超时和错误处理。

## 环境配置

文件：`document/src/config/environment.js`

公开配置包括：

- `apiBaseUrl`：Serverless 后端地址。
- `repositoryOwner`：固定为 `STILL8PM`。
- `repositoryName`：固定为 `still8pm.github.io`。
- `repositoryBranch`：默认 `main`。
- `dataRoot`：默认 `data`。

主要方法：

- `isBackendConfigured()`：判断是否允许发起工作台后台请求。

## 请求客户端

文件：`document/src/services/requestClient.js`

工厂方法：`createRequestClient({ baseUrl, timeoutMs })`

返回方法：

- `get(path)`
- `post(path, body)`
- `put(path, body)`
- `delete(path)`

统一行为：

- 默认超时 10 秒。
- 使用 `credentials: include` 携带 HttpOnly 会话。
- 自动解析 JSON 响应。
- 非 2xx 响应统一抛出 `请求错误`。
- 错误包含 `status`、`code` 和 `details`。

## GitHub 数据源

文件：`document/src/services/workbenchDataSource.js`

公共方法：

- `getSession()`：读取当前登录状态。
- `listCollection(collection)`：读取数据集合。
- `getRecord(collection, id)`：读取单条数据。
- `saveRecord(collection, id, data, version)`：按版本保存数据。
- `deleteRecord(collection, id)`：删除单条数据。
- `getRepositoryStatus()`：读取仓库连接信息。

集合名称和数据编号只允许字母、数字、下划线、短横线，防止业务层构造越界
路径或不可控文件名。

## 认证服务

文件：`document/src/services/authService.js`

- `startLogin()`：跳转到后端 GitHub 登录入口。
- `logout(request)`：调用后端销毁会话。

认证服务不接收 GitHub Secret，也不把访问令牌暴露给 React 页面。

## 工作台上下文

文件：`document/src/context/WorkbenchContext.jsx`

- `WorkbenchProvider`：提供基础状态和公共服务。
- `useWorkbench()`：页面读取 `status`、`session`、`repository`、`error`、
  `dataSource`、`authService`、`refresh`。

具体业务数据不应全部塞入该上下文，应由业务页面或独立业务上下文管理。
