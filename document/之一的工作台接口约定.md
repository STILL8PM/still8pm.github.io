# 之一的工作台接口约定

## 目的

前端只调用本约定中的工作台后台接口，后台负责认证、会话管理、权限校验和存储
提供商调用。存储提供商可以是 GitHub Repository 或坚果云 WebDAV，前端不直接
保存 GitHub Token、坚果云账号或 WebDAV 应用密码。

## 通用响应

成功响应：

```json
{
  "data": {},
  "error": null,
  "meta": {
    "requestId": "请求编号",
    "version": "GitHub 文件 SHA、WebDAV ETag 或业务版本号",
    "updatedAt": "2026-01-01T00:00:00.000Z"
  }
}
```

失败响应：

```json
{
  "data": null,
  "error": {
    "code": "CONFLICT",
    "message": "数据已经被其他终端修改"
  },
  "meta": {
    "requestId": "请求编号"
  }
}
```

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/session` | 获取当前登录会话 |
| GET | `/api/storage/status` | 获取当前存储提供商状态 |
| GET | `/api/admin/storage` | 获取脱敏存储配置 |
| PUT | `/api/admin/storage` | 更新存储配置 |
| POST | `/api/admin/storage/test` | 测试候选配置连通性 |
| GET | `/api/data/:collection` | 查询数据集合 |
| GET | `/api/data/:collection/:id` | 查询单条数据 |
| PUT | `/api/data/:collection/:id` | 按版本号保存单条数据 |
| DELETE | `/api/data/:collection/:id` | 删除单条数据 |
| GET | `/api/auth/github?mode=login` | 开始 GitHub 登录 |
| POST | `/api/auth/logout` | 销毁当前会话 |

## 存储提供商配置

```json
{
  "provider": "github",
  "github": {
    "owner": "STILL8PM",
    "repository": "still8pm.github.io",
    "branch": "main",
    "root": "data"
  },
  "nutstoreWebdav": {
    "basePath": "/workbench/data"
  }
}
```

坚果云 WebDAV URL、账号和应用密码只配置在 Serverless 密钥环境中，接口只能
返回脱敏状态。切换提供商之前必须执行连通性检查，失败时保留原配置。

## 写入约束

`PUT` 请求体必须包含：

```json
{
  "data": {},
  "version": "当前版本号或 null"
}
```

后台必须使用乐观锁校验版本号。版本不一致时返回 `409 CONFLICT`，由页面
提示用户重新加载并决定是否合并，禁止静默覆盖其他终端的修改。

## 错误编码

| 编码 | 含义 |
| --- | --- |
| `UNAUTHORIZED` | 未登录或会话失效 |
| `FORBIDDEN` | 没有目标仓库权限 |
| `NOT_FOUND` | 数据不存在 |
| `CONFLICT` | 数据版本冲突 |
| `RATE_LIMITED` | GitHub 接口限流 |
| `VALIDATION_ERROR` | 数据格式不合法 |
| `NETWORK_ERROR` | 网络或后台不可用 |
